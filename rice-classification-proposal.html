Research Project Proposal — Computer Vision / Agriculture

Hybrid ResNet & Sparse Coding Framework for Automated Rice Grain Classification

A deep learning framework that pairs ResNet's hierarchical feature extraction with Sparse Coding's compact, discriminative representations — aimed at improving rice grain classification accuracy while cutting redundant computation.

Alternative, research-oriented titleAn Efficient Hybrid Deep Learning Framework Based on ResNet and Sparse Coding for Rice Grain Classification
01

Background

Rice is one of the world's most important food crops. Manual inspection of rice grains for identifying varieties, damaged grains, impurities, and quality is time-consuming, labor-intensive, and prone to human error. Automated computer vision systems can improve consistency and efficiency in quality assessment.

Although deep learning models such as ResNet achieve high classification accuracy, they often extract redundant features and require substantial computational resources. Sparse Coding provides compact and discriminative feature representations but lacks the powerful hierarchical feature extraction of deep neural networks.

There is limited research on combining ResNet with Sparse Coding for rice grain classification. A hybrid approach may improve classification performance while learning more robust and informative feature representations.

02

Problem Statement

Existing rice grain classification methods primarily rely on conventional CNN architectures or handcrafted features. These methods may not efficiently capture discriminative characteristics across different rice varieties and grain qualities.

There is a need for an efficient hybrid model that combines the deep feature extraction capability of ResNet with the compact feature representation of Sparse Coding to improve classification accuracy and robustness — using publicly available rice grain image datasets.

03

Project Summary

This project proposes a hybrid deep learning framework for automated rice grain classification using ResNet and Sparse Coding. ResNet extracts high-level visual features from rice grain images, while Sparse Coding transforms these features into sparse and discriminative representations.

The hybrid model aims to improve classification accuracy, reduce redundant feature learning, and enhance generalization. The system will be trained and evaluated using a publicly available rice image dataset obtained from Kaggle or IEEE DataPort. Performance will be compared with conventional deep learning models using standard evaluation metrics such as Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

Initial Steps

Find the dataset

Search Kaggle and IEEE DataPort for a rice image dataset — ideally around 75,000 images with multiple, balanced classes.

Read 10–15 research papers

Cover rice classification, ResNet, Sparse Coding, and hybrid CNN + sparse-representation models.

Rice Grain Classification DLResNet for Image ClassificationSparse Coding Image ClassificationDictionary LearningHybrid CNN Sparse Coding

Install the development environment

Python 3.11 with PyTorch or TensorFlow, OpenCV, NumPy, Pandas, Matplotlib, Scikit-Learn, and Jupyter Notebook.

Explore the dataset

Understand class count, images per class, resolution, color format, class imbalance, and the train/test split.

Build the baseline model

Progress ResNet18 → ResNet34 → ResNet50, measuring accuracy, precision, recall, and F1-score at each stage.

Learn sparse coding

Dictionary learning, feature encoding, sparse representation, and L1 regularization — using sklearn.decomposition.DictionaryLearning and SparseCoder.

Build the hybrid model

Chain ResNet's deep feature vector into Sparse Coding, then feed the sparse feature vector into the classification layer.

Evaluate performance

Accuracy, precision, recall, F1-score, confusion matrix, and ROC curve where applicable — benchmarked against CNN, VGG16, MobileNet, and plain ResNet.
